# Rota — Kişisel Takip

Kalori, ev antrenmanı, su ve vücut ölçümlerini takip etmek için tek sayfalı bir web uygulaması.

## GitHub Pages

Repo kök dizininden statik olarak yayınlanabilir. Yayın adresi:

`https://anilatess.github.io/anil-fit/`

Sayfa HTTPS altında çalıştığında ana ekrana ekleme ve Service Worker çevrimdışı önbelleği kullanılabilir. Kişisel kayıtlar tarayıcının yerel depolamasında tutulur; düzenli yedek almak için uygulamadaki **Yedek indir** özelliğini kullanın.
